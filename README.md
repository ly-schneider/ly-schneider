# Mein erstes Projekt war furchtbar. Aber es lief.

Das war mit 11, und seitdem habe ich nicht mehr aufgehört. Mit 16 standen die ersten Systeme in Produktion, mit 17 kam das bisher grösste: ein komplettes Food-Ordering-System mit Custom POS, Mobile Ordering inklusive Online-Zahlung und einem Hardware-Konzept, das ins enge Budget passen musste. Konzipiert, beraten, entwickelt, alles selbst.

Was mich antreibt, ist eine einzige Frage: «Warum gibt es das noch nicht?»
